# Hardware Tracker

This document tracks the locations and statuses of all of our batteries.
The naming system consists of three parts. A category followed by a type and a number.
For example, a OV9281 camera could be labeled "CA03" (Camera of type A numbered 3).

## Cameras

'A' means OV9281, 'B' is a OV2311, and 'C' is a OV9782.

All cameras need to be named with [this](https://docs.arducam.com/UVC-Camera/Serial-Number-Tool-Guide/) tool to work better with photonvision. Check the corresponding column for status on this
